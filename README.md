# ziksz Website

Website portofolio pribadi yang menampilkan profil, proyek, karya visual, layanan, dan informasi kontak dalam pengalaman antarmuka yang modern, interaktif, dan berfokus pada personal branding.

## Live Demo

Website dapat diakses di:

[https://ziksz.vercel.app/](https://ziksz.vercel.app/)

## Tentang Proyek

`ziksz-website` adalah website portofolio statis yang dibangun menggunakan `HTML`, `CSS`, dan `JavaScript` tanpa framework. Proyek ini dirancang sebagai representasi digital personal yang menampilkan identitas, minat, hasil karya, serta media untuk memperkenalkan proyek dan layanan secara lebih profesional.

Website ini menggabungkan tampilan minimalis gelap, navigasi bergaya aplikasi, animasi interaktif, serta susunan konten yang dibuat untuk memberi pengalaman yang lebih hidup kepada pengunjung.

## Fitur Utama

- Halaman portofolio single-page dengan beberapa section terpisah.
- Loading screen interaktif dengan progress indicator.
- Navigasi antarhalaman dengan transisi horizontal.
- Dock navigation bergaya modern dengan animasi klik.
- Custom cursor untuk pengalaman desktop yang lebih interaktif.
- Dukungan navigasi keyboard dan swipe gesture.
- Section profil yang menampilkan bio, role tags, dan statistik singkat.
- Section project showcase untuk menampilkan proyek yang sudah dibuat.
- Gallery dengan filter kategori `All`, `Photo`, dan `Video`.
- Lightbox gallery untuk menampilkan konten visual secara lebih fokus.
- Section sosial media untuk mengarahkan pengunjung ke platform eksternal.
- Section layanan untuk menampilkan jasa yang tersedia.
- Section contact dengan ajakan kolaborasi melalui email.
- Integrasi status dan avatar Discord menggunakan `Lanyard API`.
- Deploy ringan dan cepat karena berbasis website statis.

## Teknologi Yang Digunakan

## Halaman / Section

- `Profile` untuk menampilkan identitas utama dan bio singkat.
- `Projects` untuk menampilkan proyek yang telah dibuat.
- `Gallery` untuk menampilkan karya visual berupa foto dan video.
- `Socials` untuk menghubungkan pengunjung ke media sosial.
- `Services` untuk menawarkan layanan yang tersedia.
- `Contact` untuk mempermudah komunikasi dan kolaborasi.
- `Blog` disiapkan sebagai ruang artikel dan pemikiran pribadi.

## Cara Menjalankan Secara Lokal

Karena proyek ini adalah website statis, kamu bisa menjalankannya dengan sangat sederhana.

1. Clone repository:

```bash
git clone https://github.com/zikssu/ziksz-website.git
```

2. Masuk ke folder proyek:

```bash
cd ziksz-website
```

3. Buka `index.html` langsung di browser.

Untuk pengembangan yang lebih nyaman, kamu juga bisa menjalankannya dengan local server, misalnya memakai VS Code Live Server.
